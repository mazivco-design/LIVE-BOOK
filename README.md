# LIVE BOOK — ספר חי

ספרייה של ספרי ילדים אינטראקטיביים בעברית לאייפד.
בוחרים ספר, קוראים כל דף בקול, הזיהוי הקולי בודק שהקריאה נכונה, ובסוף הדף הציור מתעורר לחיים.

אתר: https://mazivco-design.github.io/live-book/

## איך משתמשים
- פותחים בספארי באייפד
- בוחרים ספר מהספרייה
- לוחצים על 🎤 וקוראים בקול
- לחיצה על מילה — האייפד מקריא אותה
- 🏠 חוזרים לספרייה. ספר שנקרא עד הסוף מקבל ⭐

## איך מוסיפים סיפור
בתוך `index.html`, במערך `BOOKS`, מעתיקים בלוק של ספר ומשנים:

```js
{
  id: 'shem-babli',            // שם קצר באנגלית, בלי רווחים
  title: 'שֵׁם הַסֵּפֶר',
  cover: 'p1',                 // איזה ציור על הכריכה
  pages: [
    { text: 'הַטֶּקְסְט שֶׁל הַדַּף הָרִאשׁוֹן.', scene: 'p1' },
    { text: 'הַטֶּקְסְט שֶׁל הַדַּף הַשֵּׁנִי.', scene: 'p2' }
  ]
}
```

דף "כל הכבוד" בסוף נוסף לבד. הציורים נמצאים ב-`SCENES`.
