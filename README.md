# LIVE BOOK — ספר חי

ספר ילדים אינטראקטיבי בעברית לאייפד.
הילד קורא את הדף בקול, הזיהוי הקולי בודק שהקריאה נכונה, ובסוף הדף הציור מתעורר לחיים.

- פותחים בספארי באייפד (צריך https — GitHub Pages מתאים)
- לוחצים על 🎤 וקוראים
- לחיצה על מילה — האייפד מקריא אותה
- את הטקסט של הדפים משנים במערך `PAGES` בתוך `index.html`
